# 小说创作者需求问卷分析辅助材料

**当前仅有模拟数据，仅供流程测试。不得将本目录模拟频数、图表或草稿作为真实调查结果提交。**

问卷唯一结构依据为用户2026-10-17提供的15题及规则。项目背景依据PROJECT_CONTEXT v1.7；本任务不修改项目范围、论文目录或第二、三章正文。

## 文件与用途

- `questionnaire.json`：完整题目、原选项、题型、最大选项数、互斥及完整作答规则。
- `CODEBOOK.md`：字段和选项编码，其他填空独立保存。
- `SIMULATED_30.csv`：30份测试答卷，每行显著标注模拟来源。
- `analyze.py`：可复用模拟生成、CSV/Excel导入、校验、描述统计和制图脚本。
- `mapping.example.json`：真实Excel原始列名、原始值到编码的明确映射模板。
- `simulation_results/`：各题统计、有效人数、逐卷校验、开放文本、运行摘要及Q4/Q8/Q12的PNG和SVG。
- `WRITING_TEMPLATE.md`：研究方法、统计结果、需求归纳、局限性模板，不是可直接提交的调查结论。
- `test_analysis.py`、`VALIDATION.md`：边界测试与执行记录。

## 固定统计口径

总答卷=有效有创作经历答卷（A/B/C）+有效无创作经历答卷（D）+无效答卷。所有人均须填写Q1—14，Q15选填。Q1=D不使答卷无效，不因D群体回答实际经验题而自动判定矛盾或删除。

当前采用整卷完整性校验：任一必答漏答、非法选项、重复选择、超选、互斥冲突、其他说明缺失使整卷无效，并列出原始行及原因，不修改原始答案。该规则属于数据处理约定，应在真实数据分析前确认；不以答案是否支持系统功能作为排除标准，不因跨题态度看似不同就自动判无效。当前未设置未获确认的答题时长阈值、IP或重复答卷排除标准；这些需结合真实导出元数据人工制定和记录。

所有题均输出三套分组统计：全体有效受访者、有创作经历（A/B/C）、无创作经历（D）。每条统计记录注明群体；频数是该群体选择该选项的人数，百分比分母为该题该群体有效答题人数，保留两位小数。多选合计可超过100%；无有效人数时百分比留空。Q15统计填写及未填写人数，填写率以该群体有效答卷数为分母。开放文本在全体及所属子组中分别列出，不能跨群体相加当作独立样本。

实际经验类Q2—Q6应以A/B/C群体为主，全体与D结果保留供对照；D群体回答不能解释为亲历的创作困难或使用经验。Q8、Q12等预期偏好题以全体有效受访者为主，并可查分组结果。Q4图使用A/B/C；Q8和Q12图使用全体有效受访者，图内注明群体与分母。这是分析口径，不改变题目、不排除D群体合法作答。

模拟生成使用固定种子20261017，30份全部填写Q1—14，Q15选填，Q1在A—D中随机生成。各题独立模拟，不模拟人群相关结构或预设功能支持度。开放文本为显式测试占位，无真实研究含义。

## 运行与真实Excel替换

依赖：Python 3.10+、pandas、openpyxl、Pillow。当前图表使用Windows宋体；其他系统需在脚本中指定实际存在的中文字体路径。

```powershell
python -m pip install pandas openpyxl Pillow
python docs/questionnaire_analysis/test_analysis.py
```

真实数据处理步骤：

1. 从问卷星导出**逐份答卷明细** `.xlsx`，不要导入平台汇总表。保留原始文件和原始题号，建议将含身份元数据的文件保存在受控位置，不提交公开仓库。
2. 复制`mapping.example.json`为本地映射文件，将Q1—Q15映射到Excel的准确列标题，`Qn_other`映射到其他补充文本列。可用`--sheet`选择工作表名或从0开始的索引。要求第一行为列标题；如导出有说明行，请保留原件并制作有记录的导入副本。
3. 单元格支持选项字母、完整选项文本、`A. 选项文本`，多选支持英文/中文分号、竖线、问卷星常见`┋`或换行。**不自动按逗号/顿号拆分**，因为题目选项自身含有这些符号。数字编码、合并“其他”说明或不同分隔格式，必须据真实导出格式设置`value_maps`或明确的预处理副本，不能猜测选项。
4. 运行至全新结果目录：

```powershell
python docs/questionnaire_analysis/analyze.py analyze --input "D:/survey/真实答卷.xlsx" --mapping "D:/survey/mapping.json" --sheet 0 --mode real --output docs/questionnaire_analysis/real_results_run01
```

5. 先看`validation.csv`、`run_summary.json`及`question_counts.csv`，逐项人工核对排除原因、群体划分和分母；任何修订保留原始文件、规则和版本记录。再使用`statistics.csv`、图表和开放题文本。真实模式发现模拟标识会停止，不能把模拟文件改名作为真实输入。
6. 脚本对已存在结果目录报错，避免覆盖历史。再次导入使用新目录。记录输入文件、脚本及结构文件的SHA256，确保结果可追溯。

多选拆列映射示例（必须列全该题的选项列，所用列名以真实导出为准）：

```json
{"columns":{"Q4":{"option_columns":{"A":"4_A列","B":"4_B列","C":"4_C列","D":"4_D列","E":"4_E列","F":"4_F列","G":"4_G列","H":"4_H列"},"selected_values":["1"],"unselected_values":["0",""]}}}
```

这是映射片段，需合并入完整模板；遇到未配置值会报错。导出采用整格数字编码时，可用例如`"value_maps":{"Q1":{"1":"A","2":"B","3":"C","4":"D"}}`明确转换。未实际获得真实问卷星导出文件，不能保证所有导出变体无配置直接导入。

重新运行模拟分析（不重生成或改动原30份答卷）：

```powershell
python docs/questionnaire_analysis/analyze.py analyze --input docs/questionnaire_analysis/SIMULATED_30.csv --mode simulation --output docs/questionnaire_analysis/simulation_results_run02
```

所有数据本地处理，不上传第三方。统计图采用灰度、宋体、人数及百分比，PNG为2800×1640、300DPI，SVG可编辑。最终真实图表的图号与插入位置由论文作者确定，不调整锁定目录。
