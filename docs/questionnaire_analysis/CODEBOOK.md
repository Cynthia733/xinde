# 问卷字段与选项编码 V1.0

问卷结构依据：用户提供的15题原文；未从项目功能反推题目。模拟数据，仅供流程测试。

每行一份答卷；record_id为测试编号，data_origin为数据来源标识；Q1—Q14用选项字母，多选使用英文分号连接；Q15为原文文本。空白不等于否定选项；Q1=A/B/C/D均继续填写全部必答题，Q15选填。Q1仅用于分析分组，不作为有效性排除条件。其他选项补充文字在Qn_other列；选其他时须填写、未选时留空。

Q1、Q7、Q10、Q14单选，其余Q2—Q14多选，Q15选填。未限制数量的多选最多为该题选项数，但互斥约束始终有效。
