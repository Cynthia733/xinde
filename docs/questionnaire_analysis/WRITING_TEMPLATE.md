# 需求调研分析写作模板（非论文正文）

**模拟数据，仅供流程测试。当前尚无正式调查数据。以下均为占位模板，不得将模拟结果或虚构的发放、回收经历填入后提交。**

## 一、研究方法

为了解小说创作者的写作习惯及智能辅助需求，拟使用《小说创作者写作习惯与智能辅助创作需求调查》。问卷包含15题，涵盖创作经历、工具使用、创作困难、AI辅助需求和功能偏好。第1题用于区分创作经历群体，所有选项均继续回答第2—15题。第6、8、12题最多选择3项，相关“没有困难/不希望使用”等选项设置互斥，第15题为选填开放题。

正式调查后补充：调查日期【真实日期】、招募渠道【真实渠道】、抽样方式【实际方式】、知情说明及匿名化措施【实际措施】。共回收【总数】份，其中有效有创作经历答卷【人数】份，有效无创作经历答卷【人数】份，无效【人数】份；无效判定依据和数量为【核验记录】。按各题有效答题人数计算选项比例，多选题比例合计可超过100%。本次模拟测试不是正式招募或调查，不能写作“已调查30名创作者”。

## 二、统计结果

真实数据核验后填入：第4题以有创作经历（A/B/C）群体为主要分析对象，有效答题人数为【N4】，选择【原选项文字】的有【人数】人，占【百分比】。第8题和第12题以全体有效受访者为主，分别按【N8】【N12】计算；同时保留三组统计供对照；图表按题目原选项顺序展示，保留零频数及不支持预设方案的回答。

仅描述真实数据中观察到的分布，不使用“证明”“显著提升”等因果或效果判断。第6、8、12题的限选会影响各项频数，不能把其比例直接与无限多选题作同等强度比较。第15题经匿名化及人工主题编码后报告【主题规则、人数、分母】，无主题编码则只报告填写情况，不虚构引语。

## 三、需求归纳

依据【题号、选项、真实频数】可将样本中出现的需求概括为【具体需求】。再与正式任务书和既定项目范围核对，说明【已有需求的依据或需要讨论的差异】。

应区分：问卷反映的需求偏好、文献提供的研究参考、项目自己的技术设计。Q8涉及六类辅助任务，但回答偏好不能验证Writing Skill实现效果；Q9不能证明Context Management或MCP有效；Q10也不能证明所有作者都愿意交由系统自动保存。Q14即使出现手机需求，也应如实报告与当前PC端范围的差异，不改数据、不擅自扩展基线。Q13的激励偏好不等于积分规则已得到验证。调查不替代系统功能、性能或生成效果测试。

## 四、调查局限性

根据实际情况说明【样本量、招募渠道、覆盖人群、非概率抽样、自选择偏差】。Q2—Q6等实际经验问题以A/B/C群体为主，D群体的回答不能解释为亲历经验，也不能仅因此判为无效。问卷为自报意见，不能直接代表实际使用行为或全部小说作者。选项设置、互斥和限选规则会影响回答。没有AI使用经验的创作者仍可回答预期需求，但不宜将其意见写为真实使用效果。当前模拟数据由程序生成、开放题为占位文本，完全不具有实证推断或需求验证价值。

正式写作前必须以真实数据重新生成统计、人工核验全部占位符和引用，并移除模拟材料；不能仅删除模拟标签而沿用模拟数值。本文件不修改锁定的第二章、第三章或目录，不承诺任何查重或AIGC检测结果。
