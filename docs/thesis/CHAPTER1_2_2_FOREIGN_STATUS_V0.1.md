# 1.2.2 国外研究现状

故事辅助工具不仅需要生成文字，还需要让作者选择何时、以何种方式使用模型。Wordcraft将大语言模型嵌入故事编辑器，提供续写、替换、扩展等预设操作，也允许作者输入自定义要求，将生成和修改与正在编辑的内容结合[P13]。其25人短故事研究比较了完整工具、仅续写和聊天三种界面，完整工具获得了较高的有用性评分，部分未被原样采用的建议仍能启发构思[P13]。这种交互方式关注作者对建议的选择，为智能辅助而非自动代写提供了参考。实验范围是短时短故事写作，不能据此推断长期小说创作效率。

当研究对象转向较长故事时，连续生成需要协调故事计划、前文内容与当前推进目标。Re³采用规划、起草、重写和编辑四个阶段，先形成包含场景、人物和大纲的结构化计划，再随生成过程更新所需上下文。重写阶段通过候选重排考察连贯性与大纲相关性，编辑阶段检查人物属性冲突并进行局部修订[P14]。其英语故事实验报告了相对滚动窗口基线的连贯性与前提相关性改善，但编辑阶段对主要指标的改善有限[P14]。这项研究提供了动态组织故事信息的思路，可供本文处理持续创作上下文时参考；具体资料选择仍需按本项目任务确定。

较长故事即使表达流畅，也需要单独检查前后内容是否一致。Lost in Stories建立ConStory-Bench，并将一致性问题划分为5类、19个子类，涉及人物记忆、时间关系和世界规则等方面。配套的ConStory-Checker通过提取、配对相关内容，记录冲突依据与位置，研究长故事的一致性检测和评价[P15]。该研究以英语故事为主，对伏笔、反转等有意安排仍存在判断限制[P15]。上述工作分别关注协同操作、连续生成和一致性评价，为作者控制、上下文组织与检查提供了研究参考；它们针对不同研究任务，并不等同于本文完整的创作系统。
