# 2.7 本章小结

本章围绕小说智能辅助创作系统的开发需要，介绍了Vue 3及相关前端技术、Spring Boot、Spring MVC和MyBatis-Plus后端技术，以及MySQL数据库，分析了技术选型理由，并说明前后端分离框架中界面交互、业务处理与数据存储的协作关系。这些技术分别用于组织创作界面、处理业务请求和保存相关创作数据。
