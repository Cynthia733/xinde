# 1.2.1 国内研究现状

与本课题相关的中文研究涉及生成要求的表达、故事文本生成、长文本处理和作者使用等问题。生成内容能否贴合任务，是其中的一个关注点。提示学习综述将模板设计与答案处理作为重要环节，指出人工模板依赖任务经验，并对措辞较为敏感[P05]。受控文本生成研究则从输入条件和指定属性出发，梳理模板、控制标记等多种方法，讨论结构化输入的表示与忠实度问题[P06]。前者侧重如何表达任务，后者关注如何约束输出；这些方法各有适用条件，不能保证生成结果完全符合要求，也不能直接等同于应用系统的任务编排。

在中文叙事任务中，生成内容与前文的联系需要通过具体实验考察。帅奇等研究中文故事结尾生成，将故事末句作为目标，其余内容作为输入，设计正向增强与反向对比相结合的训练方案[P07]。评价既使用文本重合、语义相关和词汇多样性等自动指标，也通过人工评分考察流畅、连贯、顺序、因果和情感合理性。实验报告中，多项重合或相关指标较高，但词汇多样性指标降低，人工评价也并非各项最优[P07]。这提示评价时需分别考虑表达和叙事关系，不能用单一分数概括质量。该研究针对结尾句生成，与跨章节持续续写不同，其结果不能直接推广到长篇小说。

文本篇幅增加后，推断所需资源与生成可靠性还需分别考察。长文本推断优化综述从模型、计算和系统三个层面整理方法，讨论计算、存储与时延的权衡[P08]。这类研究关注推断效率，并不直接评价小说上下文选取或创作质量。可靠性研究则区分对来源不忠实与不符合现实事实的情况，并指出开放式生成允许增加输入之外的信息[P03]。对小说而言，合理新增情节与违背既定设定不能混为一谈。检测需要结合任务和判断依据，不能因为内容未在前文出现就认定为错误；资源优化与可靠性评价也不能相互替代。

AI参与文学创作还涉及作者如何选择和使用工具。晏青、黄丝雨通过观察与18名签约作者的访谈，分析素材准备、创作辅助等使用情境，发现部分受访作者会限制AI用途，并以自己的构思指导生成；样本以中尾部和兼职作者为主，不能代表全部网络文学作者[P09]。李玉萍从理论与案例层面讨论工具关系及数据依赖，主张作者筛选反馈、保持自身审美判断，而非通过对照实验验证创作效果[P10]。上述研究提供了方法、实验和作者使用方面的不同依据，其对象与评价目标并不相同，借鉴时仍需结合具体创作任务。
