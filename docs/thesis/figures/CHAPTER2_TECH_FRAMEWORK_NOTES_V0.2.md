## 技术分区及关系

- **前端技术：**Vue 3、Element Plus、Vue Router / Pinia、Axios、ECharts位于PC浏览器分区，通过HTTP/REST业务接口访问后端，属于B/S前后端分离架构。
- **后端技术：**Java 17、Spring Boot、Spring MVC、MyBatis-Plus、JWT位于同一个后端应用。业务Service组织业务处理，经MyBatis-Plus访问MySQL。图中省略小版本号以减轻信息密度，正式版本仍为Spring Boot 3.5.16与MyBatis-Plus 3.5.17。
- **智能辅助技术：**Writing Skill、Context Management、LLM接口调用及MCP位于后端应用内部，不代表独立部署的AI业务系统。LLM框内使用“LLM接口调用”，以区别后端调用职责与应用外的模型服务。
- **MCP：**Client与Server均被包含在同一后端边界内；二者连接明确标注“Streamable HTTP”“真实回环通信”，不是普通Java直调。Server仍复用业务Service查询授权资料，未因省略详细箭头而取消权限校验、Resource/Tool或真实协议要求。
- **数据存储：**MySQL位于后端应用边界外的数据存储分区，唯一指向它的连接来自后端MyBatis-Plus。没有浏览器或外部模型直连数据库。
- **外部LLM：**单独放在后端边界之外，由后端“LLM接口调用”连接。这里的框是外部服务，不表示本系统训练或本地部署模型。

整体最外框仅用于版面归组，不是单一进程或部署边界；明确标有“Spring Boot后端应用”的内框才表示后端应用范围。箭头表示主要访问方向，响应与资料返回未逐一绘制。

未保存正文、选中文本和作者要求仍可直接进入Context Management；模型结果仍需作者确认后经普通业务接口保存。这些原则按2.6与项目基线保留，按本轮简化要求不在图中展开。
