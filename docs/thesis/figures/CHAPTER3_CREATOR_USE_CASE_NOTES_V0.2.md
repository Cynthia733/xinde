## 4. UML与视觉核验

保留一个系统边界矩形、边界外左侧一个标准小人和九个边界内椭圆。九条关联为普通无箭头实线，没有用例间流程箭头，没有include/extend或技术组件参与者。画布底色虽使用无描边矩形表达，但不构成第二个系统边界。

已实际打开V0.2 PNG进行视觉检查：九个椭圆完整、大小统一；中文正常且居中，无文字溢出、重叠或线条遮挡；关联线不穿过其他椭圆。九条线只在参与者端点汇聚，其余无交叉。关联线穿过系统边界是正常的跨边界关联，不表示流程。黑色细线、纯白底、宋体，无阴影、渐变或图标，符合传统论文用例图风格。

## 5. 尺寸与Word排版

SVG画布为1000×960；PNG为3000×2880像素，300 DPI。PNG依据SVG相同元素绘制，使用本机宋体；SVG无远程依赖。跨机器使用SVG时应核对宋体是否可用，PNG已固定字体外观。

建议按14—16厘米宽度等比例插入，高约13.44—15.36厘米；32画布字号约为12.7—14.5磅，正文宽度内可读，不需缩小到细密字体。图文题注保持同页，优先SVG，PNG作为兼容版本。具体分页和打印效果仍需最终Word导出后复核，不能把本次PNG预览等同已完成Word排版。
