# 3.2 系统功能需求分析

本系统面向PC端小说创作者，围绕持续写作中的作品组织、正文编辑、资料维护和智能辅助需求划分功能。系统设置创作者和管理员两类角色，创作者负责本人作品与相关资料的管理，管理员承担必要的基础管理职责。功能划分以角色权限和业务对象为依据，将日常写作、稿件处理及创作辅助安排在相应业务组中。系统功能结构如图3-1所示。

图中创作者功能以作品创作为主线，涵盖创作入口、内容管理、写作过程与智能辅助，并保留激励和沉浸体验等辅助功能。个人创作统计仅使用当前登录用户的真实业务记录，反映其创作进度与辅助使用情况。AI输出作为候选内容供作者查看，作者可采用、修改或放弃，未经确认不能覆盖正式稿件。管理员功能保持轻量化，其管理范围应与创作者的私人资料访问权限区分。
