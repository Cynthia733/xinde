# 1.4 论文组织结构

本文共分为六章，各章主要内容如下。

第一章为绪论，介绍小说智能辅助创作系统的研究背景与意义，梳理国内外相关研究现状，说明本文的主要研究内容与论文组织结构。

第二章为关键技术研究，介绍系统采用的前端、后端和数据库相关技术，以及大语言模型、Writing Skill、Context Management和MCP协议的概念与作用，并说明系统技术框架及各部分的联系。

第三章为系统需求分析，从技术、经济、操作和社会四个方面分析可行性，分别说明创作者与管理员的功能需求，并明确性能、安全性和可靠性等非功能需求，为后续设计与测试提供依据。

第四章为系统设计，介绍整体架构、功能概要和主要业务流程，重点说明智能创作辅助模块中的任务编排、上下文管理、MCP资源与工具访问，以及模型调用和作者确认之间的配合，并给出数据库概念结构与表设计。

第五章为系统实现，介绍用户认证、创作者端主要业务和管理员功能的具体实现，分别说明六类智能创作辅助功能及MCP上下文访问的实现方式，展示系统主要功能的界面与操作流程。

第六章为系统测试，说明测试环境与方法，开展功能和非功能测试，针对上下文续写、一致性检查与作者确认进行智能创作辅助专项测试，并验证MCP调用链路，对测试结果进行分析。
