# 1.3 主要研究内容

本文面向小说创作者的持续创作过程，设计并实现基于Spring Boot、Vue和大语言模型的小说智能辅助创作Web系统。围绕作品构思、资料维护、正文写作和修改等操作，将创作管理与模型辅助结合，形成从创作准备到候选内容处理的基本流程。系统以作者的创作要求为依据，由作者判断生成建议是否符合作品需要，并保留对内容采用和修改的最终决定权。

业务部分围绕用户与作品管理、创作资料与正文管理、创作过程及稿件管理展开。系统以邮箱注册、登录和身份认证为基础，将作品及卷章节组织与正文编辑相衔接，统一维护人物及关系、世界观和大纲等创作资料。围绕日常写作安排过程管理和辅助功能，支持作者整理、查阅及保存稿件，并设置轻量管理员功能，承担必要的基础管理。

智能辅助部分通过Writing Skill组织大纲规划、人物塑造、情节构思、上下文续写、文本润色和一致性检查六类任务。针对不同任务所需资料的差异，设计Context Management，从作品信息、人物及关系、世界观、大纲、章节和已有章节摘要中选择并组织上下文，与作者当前要求共同提供给外部大语言模型。模型输出作为候选返回，由作者决定采用、修改或放弃，未经确认不能覆盖正式稿件。一致性检查提供潜在冲突及修改建议，供作者复核。

为统一智能任务获取创作资料和调用必要工具的方式，系统引入MCP，设计面向创作上下文的Resource和Tool，使相关任务能够访问作品设定和章节信息。MCP作为工程集成的一部分参与智能辅助流程，上下文管理负责按任务组织取得的资料。系统采用Spring Boot与Vue前后端分离架构完成实现，并从系统功能、智能创作辅助、非功能需求及MCP调用链路等方面开展测试，验证系统主要功能和业务流程是否符合设计要求。
