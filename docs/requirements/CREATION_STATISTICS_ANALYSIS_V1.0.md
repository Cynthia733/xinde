# 创作统计与分析 V1.0——正式功能范围

确认日期：2026-10-07。依据：PROJECT_CONTEXT v1.7及本轮用户正式决定。以下均为需求，不表示已经实现。

## 1. 定位与完整功能

面向当前登录创作者，仅使用本系统真实业务数据。页面名称“创作统计与分析”，沿用ECharts及既有个人可视化页面，不新建重复统计系统。全部作品/指定作品筛选仅限本人归属。

| 功能 | 正式内容 | 展示 |
| --- | --- | --- |
| 数据总览 | 作品总数、章节总数、累计创作字数、本月新增字数、当前连续创作天数、写作计划完成率 | 顶部统计卡片 |
| 每日字数趋势 | 近7天/近30天每日实际新增创作字数 | ECharts折线图，不以当前章节总字数推算历史新增 |
| 作品创作情况 | 作品名称、当前总字数、章节数量 | 柱状或横向柱状图，支持全部/单部作品 |
| 写作计划完成 | 字数目标（如月度目标）、已完成字数、完成率 | 进度条，复用现有计划，不扩展复杂项目管理 |
| 创作活跃 | 本月创作天数、当前连续天数、最长连续天数、日均字数、单日最高字数 | 基于真实创作记录 |
| AI辅助使用 | 六类Skill各自使用次数、AI总调用次数、作者采纳候选次数、候选采纳率 | 使用次数柱状图，基于调用及作者确认记录 |

六类Skill保持大纲规划、人物塑造、情节构思、上下文续写、文本润色、一致性检查。LLM + Writing Skill + Context Management + MCP及作者确认保存不变。

页面按筛选、总览、字数趋势、作品情况、计划、活跃、AI使用组织。近7/30天只作用于趋势，不改变“本月”等指标时间含义；其他指标期间须明确标注。

## 2. 排除与保留

撤销行业创作趋势、行业热门题材/标签热度、行业榜单、第三方平台趋势及与Skill联动。不使用起点、番茄、晋江等平台数据，不做爬虫，不构造热度指数，也不保留人工维护或导入行业数据的替代方案。

不含全站作者/作品排行榜、跨用户比较、AI质量评分、爆款预测、复杂画像及拼字成绩统计。拼字房间保持独立业务；其他激励、兑换、禅模式、音乐、搜索等功能不变。原写作时长等未列入本模块V1.0的展示方向不作为本页额外必做项，不删除其他模块的写作计时需求。本模块不作为新的核心创新点。

## 3. 数据库V1.0需要提供的记录能力

以下为逻辑数据需求，不锁定具体表名或字段名。

| 对象 | 必须能够取得或关联的数据 | 目的 |
| --- | --- | --- |
| 用户/作品/章节 | 用户归属、作品和章节关联、有效状态、当前正文字数及统计时点 | 本人范围与稿件存量统计 |
| 创作变化记录 | 作者、作品、章节、事件时间/统计日、操作来源、可去重的保存或变更标识、计算新增所需的变化依据 | 历史增量可复核，重复/自动保存不重复累计 |
| 写作计划 | 所属用户与作品、目标期间、字数目标、状态、完成量依据 | 计划与实际创作采用一致口径 |
| AI调用记录 | 用户/作品、Skill类型、逻辑请求关联、时间、状态及重试关系 | 区分请求、模型调用及成功生成；MCP读取不算AI调用 |
| 候选和作者确认 | 候选标识、所属调用、生成状态、作者及作品、采用/修改/放弃状态、确认时间、保存关联与去重依据 | 由真实作者操作和业务结果计算采纳，不将展示或生成自动算采纳 |

当前章节快照不能单独证明历史每日新增；每日记录须能追溯业务事实。优先复用既有章节版本、调用、候选和保存记录，不要求记录每次按键，也不为统计额外保存敏感Prompt全文。是否独立每日表、汇总表或缓存，在统一模型中决定；汇总应可复核或重算，不随意增加冗余表。

## 4. 后续必须确定的口径和未决事项

1. **字数与新增：**汉字/英文/空白/标点的规则；追加、删除、等长替换、删后重写如何计入。不能未经论证直接采用每次保存正字数差之和，恢复和重复编辑可能造成重复计数。
2. **操作来源：**TXT旧稿导入、粘贴、AI采纳、版本恢复对每日新增和计划完成量的影响；不得将导入旧稿直接宣称为当天实际创作。先保留来源事实，具体纳入规则后续确定。
3. **存量与累计：**当前作品字数和累计创作字数的定义及差异，删除/恢复作品章节后的处理，不混用存量和历史增量。
4. **日历与活跃：**时区、日切点、近7/30天是否含当天、创作日判定、当天尚未创作时的连续天数、最长连续期间、日均分母及单日最高统计期间。签到或登录不能代替真实创作记录。
5. **计划：**重叠计划、全作品/指定作品汇总、不同目标周期、无计划/零目标与超额完成的显示规则。
6. **AI计数：**失败/取消/重试/重新生成的计入规则，一次请求多候选的计数；采纳率分子分母单位、期间与观察时点；修改后采纳、重复确认、撤销及建议类Skill的采纳定义。调用、成功生成、候选、采纳必须区分，采纳率不能解释为质量评分。
7. **筛选与空数据：**无作品关联AI任务归属、单部作品总数含义、缺失历史记录及零分母显示。历史无记录不自动等同已证明没有创作，不伪造图表数据。
8. **物理设计：**表字段、索引、唯一约束、事务去重、汇总时机、重算与原始记录保留策略，在数据库V1.0统一决定，不新增复杂基础设施。
